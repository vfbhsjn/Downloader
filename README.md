# Downloader

ربات دانلودر حرفه‌ای تلگرام — ۱۳ پلتفرم

## پلتفرم‌ها

📸 اینستاگرام | 🎬 یوتیوب | 📱 تیک‌تاک | 🎵 اسپاتیفای
📌 پینترست | 🎧 ساندکلاد | 🐦 توییتر | 🎥 آپارات
🟠 Reddit | 🟣 Twitch | 🔵 Facebook | ⚫ Rumble
🔗 لینک مستقیم

## قابلیت‌ها

- 🌐 دو زبانه (فارسی/انگلیسی)
- 🎨 دکمه‌های رنگی
- 📊 پنل ادمین حرفه‌ای
- 🔒 امن

## نصب

1. کلون کن
2. `.env` بساز (با الگوی `.env.example`)
3. `pip install -r requirements.txt`
4. `python -m bot.main`

## Railway

1. پروژه را به Railway وصل کن
2. متغیرهای محیطی `BOT_TOKEN` و `ADMIN_IDS` را ست کن
3. Deploy کن

## متغیرهای محیطی

| متغیر | توضیح |
|-------|-------|
| `BOT_TOKEN` | توکن ربات از BotFather |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها (جدا شده با کاما) |

## دستورات

- `/start` — شروع و انتخاب زبان
- `/help` — راهنما
- `/language` — تغییر زبان
- `/admin` — پنل ادمین (فقط ادمین)
- `/stats` — آمار ربات (فقط ادمین)
- `/top` — پلتفرم‌های محبوب (فقط ادمین)
- `/broadcast` — ارسال همگانی (فقط ادمین)
- `/ban` و `/unban` — مدیریت بن کاربر (فقط ادمین)
- `/setwelcome` — تغییر پیام خوشامد (فقط ادمین)

برای دانلود کافیست لینک پلتفرم را مستقیم ارسال کنی.
